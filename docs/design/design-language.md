# שפת העיצוב של מערכת המעבר דרומה

המסמך מתעד את שפת העיצוב שנגזרה ממסכי ההשראה שסופקו, ומשמש מקור אמת יחיד
לרכיבי ה-UI. כל הערכים ממומשים ב-`apps/web/src/theme/tokens.ts` וב-`theme/index.ts`,
כך שהחלפת ערכת צבעים היא שינוי בקובץ אחד.

## 1. עקרונות

1. **RTL מלא** — הניווט הראשי בצד ימין, הטקסט מימין לשמאל, אייקונים מיושרים בהתאם.
2. **Chrome כהה, תוכן בהיר** — סרגל עליון וסייד-בר בנייבי כהה; קנבס תוכן בתכלת-אפור בהיר.
3. **כרטיס = יחידת מידע אחת** — כל משימה, אריזה או שליחות היא כרטיס לבן עצמאי.
4. **סטטוס גם בצבע וגם בטקסט** — לעולם לא צבע בלבד (נגישות, §10.1 באפיון).
5. **פעולה ראשית אחת בולטת בכל מסך**.
6. **Mobile first לשטח** — הכרטיסים נערמים לעמודה אחת, ניווט תחתון מחליף את הסייד-בר.

## 3. טיפוגרפיה

- משפחה: **Assistant** (Google Fonts), נפילה ל-Heebo / Rubik / system-ui.
- כותרת מסך: 28/700, תת-כותרת אפורה 14/400.
- כותרת כרטיס: 17/700. מספר ישות (`#PKG-10425`): 18/700, tabular numbers.
- טקסט משני: 13/400 בצבע `slate`.

## 6. פריסה

- רוחב תוכן מרבי: 1440px, ריפוד צד 24px (16px במובייל).
- רשת כרטיסים: 3 עמודות ≥1200px, 2 עמודות ≥900px, עמודה אחת מתחת לכך.
- רדיוסים: כרטיס 14px, גלולה 999px, שדה 10px.
- צל: `0 1px 2px rgba(15,23,42,.04), 0 8px 24px rgba(15,23,42,.06)`.

## 7. מה לא מומש מהמסכים

- **צ׳אט בוט צבאי** — מחוץ לגבולות ה-MVP (§4 באפיון), ולכן לא מומש.
- **מפת לוויין של הבסיס** — האפיון מחייב מפת חדרים מבוססת נתונים (SVG) ואוסר מפות
  מסווגות או נקודות ציון רגישות. מומשה מפת קומות אינטראקטיבית באותה שפת עיצוב.
